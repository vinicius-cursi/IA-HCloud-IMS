# Linux Guest OS Preparation Guide for Huawei Cloud IMS

Before exporting a Linux virtual machine from VMware, VirtualBox, or on-premises KVM, run these preparation steps inside the guest operating system.

---

## 1. VirtIO Driver Verification

Huawei Cloud runs KVM hypervisors. Verify that VirtIO modules are compiled into your initramfs:

### CentOS / RHEL / Rocky Linux:
```bash
lsinitrd /boot/initramfs-$(uname -r).img | grep -E "virtio_blk|virtio_net|virtio_pci"
```
If no output is returned, force modules into Dracut:
```bash
echo 'add_drivers+="virtio_blk virtio_net virtio_pci virtio_ring"' >> /etc/dracut.conf.d/virtio.conf
dracut -f -v
```

### Ubuntu / Debian:
```bash
lsinitramfs /boot/initrd.img-$(uname -r) | grep -E "virtio_blk|virtio_net"
```
If missing, add to `/etc/initramfs-tools/modules`:
```bash
cat <<EOF >> /etc/initramfs-tools/modules
virtio_blk
virtio_net
virtio_pci
virtio_ring
EOF
update-initramfs -u
```

---

## 2. Cloud-Init Installation

Cloud-Init is required to receive credentials, SSH keys, and IP assignments from the Huawei Cloud metadata service on boot:

```bash
# Ubuntu / Debian
apt-get update && apt-get install -y cloud-init cloud-guest-utils

# CentOS / RHEL
yum install -y cloud-init cloud-utils-growpart
```

Enable standard cloud-init services:
```bash
systemctl enable cloud-init-local
systemctl enable cloud-init
systemctl enable cloud-config
systemctl enable cloud-final
```

---

## 3. Storage Mount Identifiers in `/etc/fstab` (Use UUID)

Find the UUIDs of all filesystems:
```bash
blkid
```

Edit `/etc/fstab` and replace any hardcoded device names (`/dev/sda1`, `/dev/sdb1`) with their corresponding UUIDs:
```text
# CORRECT:
UUID=6a9f4e22-1234-4567-89ab-cdef01234567 /               ext4    errors=remount-ro 0       1
UUID=1234-ABCD                            /boot/efi       vfat    umask=0077        0       1

# WRONG (will drop into Emergency Mode on ECS):
# /dev/sda1 / ext4 defaults 0 1
```

---

## 4. Networking (DHCP & MAC Cleanup)

1. Set all Ethernet interfaces to use **DHCP**.
2. Remove static MAC persistence rules generated by udev:
   ```bash
   rm -f /etc/udev/rules.d/70-persistent-net.rules
   rm -f /etc/udev/rules.d/80-net-setup-link.rules
   ```
3. On CentOS/RHEL, strip `HWADDR` and static `UUID` lines from network scripts:
   ```bash
   sed -i '/HWADDR/d' /etc/sysconfig/network-scripts/ifcfg-eth*
   sed -i '/UUID/d' /etc/sysconfig/network-scripts/ifcfg-eth*
   ```

---

## 5. Final Sanitation

Before powering down the template:
```bash
truncate -s 0 /var/log/*log 2>/dev/null || true
history -c
rm -f /root/.bash_history
rm -f /home/*/.bash_history

sync
poweroff
```
The resulting virtual disk is now ready for conversion and import into IMS.
