# Technical Specifications & Constraints - Huawei Cloud IMS

*Reference: [Huawei Cloud Support - Image Management Service (IMS)](https://support.huaweicloud.com/intl/en-us/ims/index.html)*

---

## 1. Service Overview
**Image Management Service (IMS)** manages the full lifecycle of VM templates and disk images on Huawei Cloud. Private images can be registered from:
- Running ECS instances
- Cloud Backup and Recovery (CBR) backups
- **External virtual disk files staged in Object Storage Service (OBS)** *(this project's focus)*

---

## 2. Supported Image Formats

Huawei Cloud natively supports importing the following virtual disk formats:
- **QCOW2** *(QEMU Copy-On-Write v2)*: Primary open-source format for KVM hypervisors.
- **RAW**: Bit-by-bit raw disk image (supports Fast Create up to 1 TiB).
- **ZVHD / ZVHD2**: Huawei Cloud proprietary compressed formats produced by `qemu-img-hw`.
- **VMDK**: VMware ESXi / Workstation disk format.
- **VHD / VHDX**: Microsoft Hyper-V formats. *(Note: Convert VHD with `qemu-img -f vpc`)*.
- **VDI**: Oracle VirtualBox format.
- **QED / QCOW**: Legacy QEMU formats.

> [!IMPORTANT]
> **OVA Archives**: An `.ova` package is a TAR archive containing an `.ovf` descriptor and one or more `.vmdk` disk files. OVA files cannot be imported directly into IMS. They **must be extracted**, their primary VMDK isolated, and converted to QCOW2, RAW, or ZVHD2.

---

## 3. Single Disk Constraint

- **Rule**: Every system disk image (System Disk Image) imported from an external OBS file must contain **only ONE virtual disk**.
- If a source VM (from VMware, Hyper-V, or Proxmox) has multiple disks attached (e.g., `disk-0.vmdk` for `/` and `disk-1.vmdk` for `/data`):
  1. `disk-0.vmdk` must be converted and registered as the **System Disk Image**.
  2. Secondary disks must be converted and imported separately as individual **Data Disk Images**.
  3. When launching an ECS instance, attach data disk images as secondary EVS volumes.

---

## 4. Size Limits & Import Modes

| Import Mode | Supported Formats | Max File Size | Background Driver Injection |
| :--- | :--- | :--- | :--- |
| **Standard Import** | QCOW2, VMDK, VHD, RAW, VHDX, VDI | Up to **128 GiB** | Yes (automatic driver injection in background) |
| **Fast Create** | **RAW or ZVHD2 only** | Up to **1 TiB (1024 GiB)** | No (guest OS must already have native VirtIO drivers) |

### System Disk Bounds (`min_disk`)
- **Linux**: Between **10 GB** and **1024 GB**.
- **Windows**: Between **20 GB** and **1024 GB**.

---

## 5. Guest OS Requirements

### A. Native VirtIO (KVM) Drivers
Huawei Cloud ECS instances run on KVM hypervisors. The guest operating system must include VirtIO kernel modules in its initramfs/initrd:
- `virtio_blk` (Block device controller)
- `virtio_net` (Network adapter)
- `virtio_pci` (PCI bus driver)
- `virtio_scsi` (SCSI controller)

### B. Metadata Handlers (Cloud-Init / Cloudbase-Init)
- **Linux**: The `cloud-init` service must be active. It receives instance credentials, public SSH keys, and configures networking dynamically.
- **Windows**: Must have `Cloudbase-Init` installed.

### C. Persistent Storage Mounts (`/etc/fstab`)
- Partitions mounted in `/etc/fstab` and GRUB boot flags **MUST use UUID** (e.g., `UUID=xxxx / ext4 defaults 0 1`) or `LABEL`.
- **Prohibited**: Hardcoded device paths such as `/dev/sda1`. Storage controllers register as `/dev/vda` in KVM, and hardcoded paths will trigger emergency recovery mode.

### D. Dynamic Networking (DHCP)
- Ethernet interfaces must be set to obtain IP addresses dynamically via **DHCP**.
- Remove static MAC binding rules generated by udev (e.g., `/etc/udev/rules.d/70-persistent-net.rules`).

---

## 6. OBS Storage Requirements

1. **Storage Class**: The bucket storing image files must be **Standard**.
2. **Same Region**: The bucket must reside in the **same region** where the IMS image is registered.
3. **Pointer Format**: The `image_url` parameter required by the IMS API follows: `<bucket_name>:<object_key>`.
